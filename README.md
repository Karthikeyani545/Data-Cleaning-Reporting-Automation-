# 📊 Data Cleaning & Reporting Automation

An automated Python solution developed to clean raw datasets and generate analytical insights instantly. 

---

## 🚀 Project Overview
Manual data entry often leads to duplicate values, missing fields, and formatting errors. This project provides a single-click automation script that preprocesses raw data, cleans it, and generates production-ready reports and visuals.

## 🛠️ Key Features
* **Duplicate Elimination:** Automatically scans the dataset and removes identical rows to prevent skewed analysis.
* **Smart Imputation:** Handles missing textual data with defaults and substitutes missing numerical metrics using dynamic column averages.
* **Instant Reporting:** Exports the processed dataset into a structured Excel workbook.
* **Automated Visualization:** Visualizes student metrics via an auto-generated bar chart.

## 📂 File Description
* `automation.py` - The core Python logic running the automated pipeline.
* `raw_student_data.csv` - The uncleaned source file featuring 50 student records.
